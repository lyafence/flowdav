# Code of Conduct

## Our Pledge

We as contributors and maintainers pledge to make participation in this
project a harassment-free experience for everyone.

## Our Standards

Examples of behavior that contributes to a positive environment:
- Using welcoming and inclusive language
- Being respectful of differing viewpoints
- Gracefully accepting constructive criticism
- Focusing on what is best for the project

Examples of unacceptable behavior:
- Harassment, trolling, insults, personal attacks
- Publishing others' private information without consent
- Other conduct which could reasonably be considered unprofessional

## Enforcement

Report violations via GitHub Private Reporting in the Security tab. The maintainer reviews all contributions — human or AI-generated — on merit, not origin. Violations may result in temporary or permanent exclusion from the repository.
